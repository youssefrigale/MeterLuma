# MeterLuma privacy information

Updated 2026-10-15, provider-connection revision 3, for the current desktop implementation. Publisher: Youssef Rigale, Morocco. Proposed support/privacy contact: support@meterluma.com. Verify ownership of meterluma.com and operation of this mailbox before public release.

MeterLuma has no publisher account service, analytics, advertising, cloud sync, or automatic crash-report upload. It does not send your usage history or exports to the publisher. This describes the app; a future download website, mail host, or hosting provider may process separate access logs and messages and needs its own disclosures.

## On your device

The WebView stores appearance preferences, provider selections, profile labels and directory paths, history range, alert rules, and the accepted license version in local storage under `meterluma.settings.v2`. Paths and labels may contain personal information. Provider tokens and conversation content are not stored in these preferences. Native Claude/Cursor quota lookups temporarily read their existing access tokens into process memory, send them only to the corresponding fixed provider HTTPS usage endpoint, and do not copy them into a MeterLuma credential store. The license acknowledgement is local only, not an independently verified record of agreement.

When you select a local connection, the native app scans supported Claude Code or Codex session logs for usage metadata: token counts, model names, and timestamps. It reads log files that may also contain conversation text, filters records locally, and returns only usage metadata to the interface. It does not send conversations to the publisher or include them in exports. History is scoped to the selected directory on this device across sign-ins; it is not a verified account-wide billing record. The selected period is 30, 90, or 365 days. Bounded scans may omit records; the interface marks partial totals.

Successful Claude/Cursor quota snapshots and a hash of the matching credential are retained locally in MeterLuma/quota-snapshots-v1.json under the operating system cache, for at most 16 profiles. Snapshots contain usage percentages, reset times and fetch timestamps, not raw tokens, account names or conversations. A failed refresh can show the same credential's snapshot for up to 24 hours, explicitly labeled cached. Expired quota windows are removed. A successful guarded token rotation carries the same-login binding forward; other sign-in changes cannot reuse an old credential's snapshot. Delete this cache separately after quitting to remove these saved snapshots.

Native history results are cached in process memory for up to 60 seconds. MeterLuma does not create a separate persistent database of usage history. Restarting the app clears memory caches; original provider log files remain under your control. Separate profile directories let you view your own accounts without MeterLuma copying their credentials.

Provider rate-limit deadlines are saved locally in the operating system cache under MeterLuma/usage-cooldowns-v1.json, using hashed profile identifiers. This small file contains deadlines, not credentials, account names or usage figures. Refresh, preference resets and app restarts do not bypass a provider's active cooldown. Expired deadlines are removed when updated; this cache can be deleted separately after quitting the app.

Provider details can estimate recorded Claude tokens' API value locally using model prices checked October 15, 2026. This uses the same token/model metadata and makes no additional network request. Estimates are labeled, use current standard global API rates and logged cache durations (five minutes if unspecified), exclude tool fees, fast mode, regional premiums, historical prices and discounts, and are not subscription charges or bills. Days or periods with unknown model prices have no dollar total. JSON history exports may include the estimated value.

## Provider communications

Codex quota lookup starts the installed, unmodified official Codex CLI app-server and requests its documented rate-limit information. The CLI handles its own sign-in and any token renewal, and may contact OpenAI or other services according to its own configuration and policies. MeterLuma does not read or copy subscription tokens and sends no prompts or inference requests for quota lookup. Review the provider's privacy terms and your local CLI configuration. Your network provider and the provider service may receive ordinary connection information such as an IP address.

After you explicitly connect them, Claude quotas use the existing Claude Code credential (its local file or the default macOS Keychain entry) with https://api.anthropic.com/api/oauth/usage. Cursor quotas use the existing local Cursor state database, with macOS Keychain fallback, and https://api2.cursor.sh/aiserver.v1.DashboardService/GetCurrentPeriodUsage. These experimental connections follow the local-sign-in usage-request approach documented by OpenUsage; no provider endorsement or legal permission is implied. TLS is verified, redirects are disabled, responses are bounded, the usage request uses a Claude CLI compatibility User-Agent with MeterLuma identification, and errors omit raw response bodies and token values. The native quota cache lasts five minutes for a successful request and is keyed by profile and a credential/account fingerprint. Sign-in changes invalidate it. HTTP 429 responses cause a bounded cooldown. MeterLuma can renew the selected Claude Code credential file through https://platform.claude.com/v1/oauth/token when it is near expiry or receives HTTP 401. It sends the existing refresh token only to that fixed provider endpoint, requests no additional scopes, and writes back only access token, rotated refresh token and expiry. Generation checks preserve unrelated fields and refuse a changed login; the provider store offers no atomic compare-and-swap, so concurrent provider-app changes remain a best-effort check. Windows replacement preserves the original credential file ACL. Temporary files are created only beside that credential file and cleaned up. Cursor, Claude Desktop and macOS Keychain credentials remain read-only; renew those using their provider app. These services receive the access token and ordinary request/network metadata under their own policies. Official status and usage pages open in your default browser only when you choose them.

## Alerts, exports, and deletion

Alerts appear in the app while it is running, using fresh available quotas. There are no push services or notification uploads. CSV and JSON exports are created only when you request them. Desktop exports use a native save dialog. Exported files can reveal usage patterns, model names, and your profile labels; you control where they are saved and whether to share them. Exports omit credentials and local directory paths.

Remove a profile to stop reading that source. Disconnecting does not sign you out of a provider or delete its original logs. Reset settings removes MeterLuma's saved profile list, alert rules, and preferences; quitting clears in-memory results. Delete exported files separately. Uninstalling or clearing app WebView data removes saved app preferences, subject to your operating system's backup behavior. MeterLuma does not erase provider data.

## Support and applicable privacy rights

Do not send credentials, conversation logs, or unredacted screenshots in support requests. If you contact the publisher, the publisher and mail service will process what you send to handle that request. The mailbox provider, retention period, applicable lawful basis, any international transfers, and any required Moroccan CNDP formalities must be confirmed before support opens. This notice does not represent that those operations have already been configured or legally cleared. Contact the publisher for access, correction, deletion, or other applicable rights concerning data the publisher actually holds.

Children's data, additional telemetry, cloud sync, automatic updates, support uploads, or a changed hosting setup require a fresh assessment and updated information before being introduced.
