# MeterLuma legal issue review — 2026-10-15

This is a practical issue review of the repository and published primary sources, prepared with AI assistance. It is not an opinion from a Moroccan advocate, does not establish an attorney-client relationship, and does not certify worldwide compliance. The owner identified himself as Youssef Rigale, located in Morocco, and supplied support@meterluma.com as the intended contact. Domain ownership, mailbox operation, business status, and a public service address have not been verified.

The original review reflects branch `release-readiness` at commit `1b4c9c1`. Implementation notes were updated on 2026-10-20 for the local 0.1.2 candidate; this is not a new legal opinion or clearance.

## Result

**Public release is not legally cleared.** The chosen model is proprietary software free for personal use, with commercial use and redistribution restricted. Publishing source to a public GitHub repository conflicts with a strict prohibition on all copying/forking there. The Claude credential issue was resolved on 2026-10-15 by removing the Claude live-quota connector. Open items remain: the unofficial Cursor connection, the professional-use restriction in the license, required notices for the exact release binaries, owner disclosures, and consumer/privacy obligations for the actual release and intended markets.

## Findings and changes

1. **License scope and ownership.** LICENSE 1.1 identifies Youssef Rigale and permits private personal use, backups on the user's own devices, and private source modifications if source is supplied. It excludes user data/exports and separately licensed components from the restrictions. It prohibits commercial, professional, business and organizational use, selling, sharing copies and modified distributions. This matches the owner's stated preference; it is not an open-source license under the [Open Source Definition](https://opensource.org/osd).

2. **Mandatory rights and contract formation.** The license preserves non-waivable protections, software exceptions and competent court rules, includes severability, and does not impose arbitration or attempt to revoke earlier grants retroactively. Moroccan law is the stated governing law, subject to mandatory protections elsewhere. A first-use checkbox precedes local data access and the text is available in-app and packaged with the app. The acknowledgement is stored locally; it is not proof of identity or an independent agreement record. Country-specific enforceability and required publisher/address disclosures still need an advocate's assessment. For example, the EU [Software Directive](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32009L0024) contains mandatory software exceptions; a blanket restriction cannot simply remove applicable statutory rights.

3. **Claude: live-quota connector removed.** On 2026-10-15, after review of Anthropic's published text, the owner removed the Claude live-quota connector. [Anthropic's authentication documentation](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use) states that "developers may not collect, store, or intermediate Claude.ai credentials or session tokens". The removed connector read the Claude Code sign-in, sent it to Anthropic's OAuth usage endpoint with a Claude CLI User-Agent, and could renew the token with Claude Code's OAuth client ID and write it back. The previous version of this review understated that conflict and did not address the automated-access restrictions in Anthropic's Consumer Terms. MeterLuma now reads only token counts, model names and timestamps from Claude Code's local log files. It reads no Claude credential, never renews or writes one, and makes no requests to Anthropic. Saved Claude quota snapshots are discarded. Privacy revision 5 preserves this behavior and adds Codex/Cursor token-storage disclosures; users accept it again. Reading the user's own local logs uses no Anthropic service or credential. This is not a claim of provider authorization or endorsement.

4. **Codex and Cursor.** Codex quotas use the official CLI's documented [app-server rate-limit interface](https://learn.chatgpt.com/docs/app-server): MeterLuma starts the `codex` executable found on the PATH or in common install locations and requests authentication and subscription rate limits, never inference. In the new token mode, a user-supplied ChatGPT OAuth access token travels over stdin into the documented experimental external-token flow in an isolated temporary profile. The optional local mode lets the CLI handle its existing sign-in. Cursor quotas use a user-supplied access token by default, or an explicitly selected existing local sign-in, and call the same undocumented internal dashboard usage endpoint. [Cursor's terms](https://cursor.com/terms-of-service) contain broad restrictions on extracting data from the service. Whether a user-initiated, read-only lookup of the user's own allowance falls under them is an unresolved interpretation question. That the endpoint works does not mean it is permitted. Current mitigations: the connection is labeled **Unofficial** everywhere it appears, with a note that the endpoint is not endorsed by Cursor and may change or stop working. Requests carry an honest `MeterLuma/<version>` User-Agent. Provider sign-in files are never renewed or written. Accepted manual tokens are stored separately with Windows user-bound DPAPI or macOS Keychain and removed on disconnect; they require replacement when expired. A successful result is reused for 5 minutes, and the provider's Retry-After is honored for up to 6 hours. Users carry a small residual account risk, and the endpoint can change without notice. The owner may still choose to ship Cursor disabled by default until Cursor publishes a usage API or grants permission. No provider-approval claim is made.

5. **Third-party copyrights and trademarks.** The current resolved inventory contains 533 components across frontend runtime dependencies, Rust transitive/build/platform crates (including the optional updater crates), and native WebView2/LLVM runtime supplements. The LLVM runtime applies only to the superseded local GNU Windows beta; MSVC release builds do not ship it. THIRD_PARTY_NOTICES.txt preserves collected texts, provenance and exact source archive links, including MPL source availability. The generator reports no unresolved notice entries; sources include archive files, pinned upstream notices and identified companion project license texts. This inventory is not an independent legal audit. No third-party license is replaced by MeterLuma's no-redistribution term. Packages not shipped on a given platform may be listed. An exact-binary review remains necessary, especially for source-availability conditions and external system components. Provider logos (owner decision of 2026-10-16): the app shows each provider's official logo, byte-for-byte as published (Anthropic's Claude Spark from its press kit, OpenAI's Blossom and Cursor's cube from their brand pages), only beside the provider's name to identify the service. src/assets/providers/README.md records the sources and rules, and THIRD_PARTY_NOTICES.txt names each owner. The logos are not covered by MeterLuma's license. A "not affiliated with or endorsed by Anthropic, OpenAI or Anysphere (Cursor)" note appears in Connections and the tray's Help page. Terms by owner:
   - **OpenAI.** The owner accepted OpenAI's Marks usage terms on 2026-10-16 to download the logos. They grant a non-exclusive, revocable permission that requires following OpenAI's brand guidelines (Blossom in black or white only, never as primary branding) and keeping MeterLuma's own name more prominent. OpenAI may require changes or end the permission at any time.
   - **Cursor.** Its brand page publishes the assets without stated usage terms beyond the naming rule ("Cursor", not "Cursor AI").
   Provider names and logos must stay referential and must not imply endorsement. The screenshots in `artifacts/` show older logo files and must be replaced before any public use.

6. **Privacy and Morocco.** PRIVACY.md (revision 5) describes protected manual-token storage and removal, connection migration, local processing, stored directory labels/paths, bounded log scanning, the Codex CLI and Cursor communications, the local cache files and their pruning, exports, the optional updater, and deletion, including what the Windows uninstaller does and does not remove. No analytics or publisher upload service is implemented. Do not infer that this eliminates all obligations: future support emails, hosting logs, an update host or telemetry introduce separate processing. The [Moroccan CNDP guidance](https://www.cndp.ma/conditions/) requires appropriate purposes, proportionality and transparency for personal-data processing within its scope. Identify actual controllers, processors, retention, international transfers, and any applicable notification/authorization before support/hosting goes live. Applicability of Moroccan, EU/UK or other privacy rules depends on actual operations, audience and data flows; no blanket exemption is claimed.

7. **Public GitHub contradiction.** [GitHub's public-repository terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#5-license-grant-to-other-users) grant platform view/fork rights. Keep source private while strict no-redistribution is required. An owner-controlled download site can distribute the owner's binaries under the personal-use terms. A public project showcase linking official downloads needs its own compatible content terms and must not accidentally publish restricted source.

8. **Launch claims.** Do not advertise legal approval, provider affiliation or endorsement, Claude quotas or any connection to a Claude account, official Cursor support, account-wide billing, live dollar spending, guaranteed alerts, or support that has not been configured. Provider logos appear in the app only to identify each service. Do not use them on the website or in marketing without each owner's approval, and repeat the not-affiliated statement on the download page. Describe Claude as recorded local history only, Cursor quotas as unofficial, and Codex quotas as read through the user's installed Codex CLI. Dollar figures are estimated API value at list prices, not bills. History is recorded device/profile activity, limited to logs that still exist (Claude Code deletes transcripts after 30 days by default). Token connections represent supplied access tokens; optional local profiles are separate existing directories. Alerts are in-app while running and require fresh Codex or Cursor quotas. Exports contain only selected usage metadata. The former paid features are free personal-use features. Signing/notarization and verified installations are separate technical release requirements.
