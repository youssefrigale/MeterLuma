Source: [robinebers/openusage issues](https://github.com/robinebers/openusage/issues), retrieved 2026-10-26. Snapshot: 587 issues (65 open, 522 closed), including issue bodies and 1,307 retrieved comments. Pull requests are excluded.

**Review complete; implementation has stated limits.** Every one of the 587 issues has an individual disposition below. The owner requested all issues and requested providers. Pending/partly implemented rows identify remaining work; reviewing a request does not mean implementing every upstream product feature. Implemented safeguards do not imply complete feature parity or positive live QA for every provider. Existing owner data and provider sign-ins must be preserved; new integrations remain disconnected until explicitly chosen. No release or publication is authorized.

## Remaining boundaries

- Consumer Microsoft Copilot and Duck.ai have no verified quota/auth reader in this build. Their website shortcuts collect no credential and return no invented quota.
- New provider contracts still need an account owner to connect inside MeterLuma for positive live QA. Tests do not substitute for subscriptions, scoped account permissions or installed Qoder/BytePlus CLIs.
- Full history/cost support is currently Claude/Codex. Other providers expose the exact quota, balance, rated-cost or local-token subset listed above. Cursor/Grok/Antigravity durable histories, account-owned attribution and multi-key additional accounts remain pending.
- iCloud sync and WidgetKit require separate native targets, containers and signed entitlements absent from this project. Mac OS notifications now have an opt-in UserNotifications implementation; positive banner delivery remains subject to owner authorization and separate native QA. Windows OS delivery, arbitrary custom HTTP budgets, a normal window/Dock mode and per-metric ordering/visibility layouts remain unimplemented. Per-connection compact Overview cards, group-level provider ordering and layout-only restore are implemented. The optional stay-open panel and custom global shortcut cover only their stated scope.
- Current saved Claude plan labels can be stale and do not prove active/paused billing. The usage-only integration does not call a live profile/billing endpoint or read Claude Desktop safe storage.
